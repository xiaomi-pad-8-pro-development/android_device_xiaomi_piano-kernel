# Kernel prebuilts for the Xiaomi Pad 8 Pro (piano)

The kernel the piano device tree boots: the Image, devicetrees, headers
and modules, ready for the ROM build to pick up.

Goes in `device/xiaomi/piano-kernel`.

Built from the [alxp kernel](https://github.com/xiaomi-pad-8-pro-development/android_kernel_xiaomi_piano)
by [auto](https://github.com/xiaomi-pad-8-pro-development/auto), which
describes each file here. Every module is built from source; nothing is
taken from the stock firmware.
